# 🎯 Face Recognition System (Live Detection & Verification)

An intelligent **real-time face recognition** project built using **OpenCV** and **DeepFace**, designed to detect and verify faces from a live webcam feed.  
The system compares live faces against one or more reference images to determine a **match** with visual feedback — ideal for **attendance systems, authentication, or access control**.

---

## 🧠 Features

- 🎥 **Live Camera Detection** — captures frames directly from the webcam.  
- 🧩 **Face Verification** — compares live input with stored reference image(s).  
- ⚡ **Multi-threaded Processing** — ensures smooth and real-time performance.  
- 🧍 **Multiple Reference Faces Support** — identify multiple authorized users.  
- 💬 **Visual Feedback** — displays “MATCH” (✅) or “NO MATCH” (❌) overlay on the screen.  
- 🔒 **Offline & Privacy-Friendly** — processes all data locally, no cloud dependencies.

---
